# 탐지 범위 정리: 테스트 자석 vs 실제 초소형 이어피스

이 문서는 실측 전 기대값과, 테스트 자석(D3×1, D4×2)과 실제 이어피스의 차이를 어떻게 보정할지 정리한다.
실측 후 `TuningDefaults.DEVELOPER` 와 이 문서의 "실측" 절을 갱신한다.

## 1. 물리 모델

작은 영구자석은 쌍극자다. 자기 모멘트 m = Br·V / μ0 (Br: 잔류자속밀도, V: 부피).

- 축 방향(N극 정면): B(r) = (μ0/4π) · 2m / r³
- 측면: B(r) = (μ0/4π) · m / r³ (정면의 절반)

거리 r 의 세제곱으로 줄어든다. 거리 2배 → 1/8. 이 앱의 결과 탭 r⁻³ 참고선이 이걸 확인하는 용도다.

### 예상 자기장 (µT, 정면 / 측면)

|---|---|---|---|---|---|---|---|---|

| D3×1 | N52 | 8.16e-03 | 1631.2 / 815.6 | 203.9 / 102.0 | 60.4 / 30.2 | 13.0 / 6.5 | 1.6 / 0.8 | 0.5 / 0.2 |
| D4×2 | N35 | 2.40e-02 | 4800.0 / 2400.0 | 600.0 / 300.0 | 177.8 / 88.9 | 38.4 / 19.2 | 4.8 / 2.4 | 1.4 / 0.7 |
| D4×2 | N52 | 2.90e-02 | 5800.0 / 2900.0 | 725.0 / 362.5 | 214.8 / 107.4 | 46.4 / 23.2 | 5.8 / 2.9 | 1.7 / 0.9 |

## 2. 실제 이어피스와 테스트 자석의 차이

### 2-1. 자석 크기·등급
- 커닝용 "쌀알 이어폰"은 수신 코일 + 아주 작은 자석(스피커 구동용) 또는 자석 자체가 진동체인 구조다. 자석은 보통 D1~D2mm, 두께 0.5~1mm 급으로 **D3×1 보다 모멘트가 0.1~0.5배** 수준으로 추정한다. 제품마다 달라 범위로 다룬다.
- 탐지 거리는 모멘트의 세제곱근으로 줄어든다: 모멘트 0.1배 → 거리 0.46배, 0.3배 → 0.67배, 0.5배 → 0.79배.
- **환산 규칙**: D3×1 로 측정한 탐지 거리 × 0.5~0.8 을 실제 이어피스 기대 거리로 둔다. D3×1 이 5cm 에서 잡히면 이어피스는 2.5~4cm.

### 2-2. 철(강자성체) 함유
- 이어피스 외피·코일 코어의 철/페라이트는 스스로 자기장을 내지 않고 지구 자기장(약 50 µT)을 끌어모아 왜곡한다. 유도 자화에 의한 변화는 대략 ΔB ≈ (V / 4πr³) · 3·B_earth. 부피 10 mm³, 3cm 에서 ≈ 0.004 µT → **센서 노이즈(0.1~0.5 µT) 아래**. 즉 철 성분은 이 방식으로는 못 잡는다. 영구자석이 있어야만 탐지된다.
- 다만 자석에 철이 붙어 있으면(요크 구조) 외부로 나오는 자기장이 커지거나 방향이 바뀔 수 있어 거리 계수가 ±30% 흔들릴 수 있다.

### 2-3. 교류 자기장 (넥루프·유도 코일)
- 수신 방식이 자기 유도(넥루프)이면 목걸이 코일에 음성 주파수(300Hz~3kHz) 전류가 흐른다. 지자기 센서 샘플링(100~200Hz)으로는 그 주파수를 직접 못 보지만, 앨리어싱되어 광대역 잡음으로 보인다 → AC RMS 지표가 올라간다.
- 전류 세기가 작아(수 mA, 몇 turn) 거리 몇 cm 안에서만 보일 가능성이 높다. 실측 항목에 "넥루프 송신 중 / 꺼짐" 조건을 추가해 AC RMS 차이를 확인해야 한다.

### 2-4. 자세·방향
- 귀 속 이어피스는 자석 축이 귓구멍 방향이라 폰이 귀 옆면에 올 때 **측면 성분**에 가깝다. 정면 값의 1/2 로 본다.
- 벡터 Δ 는 자석 방향 변화도 잡는다. 크기 Δ|B| 는 자석 자기장이 지구 자기장과 수직이면 거의 0 이 될 수 있다(실제론 ±√(B_e²+b²)−B_e 로 작게 남음). 스캔 모드의 미탐 원인이므로, 실측에서 두 지표를 함께 기록해 비교한다.

## 3. 범위 설계 (실측으로 확정할 것)

| 항목 | 사전 가정 | 실측으로 채울 값 |
|---|---|---|
| 교실 노이즈 σ (폰 고정) | 0.1~0.5 µT | 장소별 프로필에 저장 |
| 손에 들고 스캔 시 σ | 1~5 µT (손떨림·회전) | 크기 모드 σ|B| 로 측정 |
| Δ 임계값 | 3 µT (σ 의 6~30배) | 대조군(자석 없음) 95퍼센타일 × 2~3 |
| 실제 이어피스 등가 거리 | D3×1 측정 거리 × 0.5~0.8 | 실물 이어피스 확보 시 직접 측정 |
| 미탐 허용 | 3cm 이내는 잡아야 함 | — |
| 오탐 원인 | 안경, 자석 단추, 다른 폰, 책상 철제 다리, 노트북 | 각각 Δ 를 한 번씩 기록 |

프리셋 배율(민감 0.5 / 표준 1 / 보수 2)은 이 가정 위에서 정한 임시값이다. 실측 후 표준값만 `TuningDefaults.DEVELOPER` 에 반영하면 프리셋은 그 배율로 따라간다.

## 4. 실측 체크리스트 (내일)
1. 자석 없음 대조군: 책상 고정 5회, 손에 들고 스캔 5회. → σ, 대조군 Δ 분포.
2. D3×1, D4×2 각각 거리 1/2/3/5/10cm × 정면/측면 × 3회. → 결과 탭 로그 그래프에서 r⁻³ 확인.
3. 오탐 후보(안경, 다른 폰, 자석 단추) 각 1회.
4. 넥루프가 있으면: 송신 중/꺼짐 2cm, 5cm 에서 AC RMS.
5. 결과로 `TuningDefaults.DEVELOPER` 와 이 문서의 표를 갱신.
